# Проверка React UI Dauys

> История базовой версии. Для текущей сборки с InnovationSuite см. `VERIFICATION-INNOVATION.md`.

Дата: 11 ноября 2026. Среда: Windows, Node 24.15, React 19, TypeScript, Vite. Проверялась production-сборка через локальный preview на `127.0.0.1:5175`.

## Сборка

- `npm run build` проходит: TypeScript `--noEmit` и Vite production build.
- Циклические связи между manual chunks устранены. Начальный HTML preload-ит React и Motion; Three.js подгружается отдельно.
- Остаётся ожидаемое предупреждение о размере отложенного Three-чанка: около 932 КБ без сжатия / 255 КБ gzip. Предупреждение не отключалось.
- Основной UI-чанк — около 85 КБ / 27 КБ gzip; React — 222 КБ / 69 КБ gzip; Motion — 138 КБ / 46 КБ gzip; CSS — 44 КБ / 11 КБ gzip. Эти размеры не являются измерениями INP или времени загрузки.

## Фактические проверки в браузере

1. На главной отрисованы WebGL-планета со стеклянной оболочкой, орбитой и спутником, а также фоновые точки. Проверена настольная и узкая раскладка героя.
2. Выбор «IT и сервисы» включает соответствующее radio и активирует продолжение. В форме автоматически выбраны «Интеграции и IT» и подразделение IT.
3. Через форму создано предложение «Единый доступ к инструкциям — проверка React UI». Открылась карточка нового обращения со статусом «Получено».
4. Добавлен комментарий. После перезагрузки количество обращений осталось 21; поиск «React UI» нашёл созданную запись, комментарий сохранился.
5. Уведомление открыло A-008. Подтверждение поменяло статус на «Подтверждено», добавило событие в историю и обновило текст результата. Состояние сохранилось после перезагрузки.
6. Фильтр «Решено» показывает A-004 и A-008; положительный отзыв A-018 не включается в решённые проблемы и предложения.
7. Аналитика по текущим демозаписям: 21 обращение, 2 с решением, средний первый ответ 6 часов, 12 просроченных, 1 результат подтверждён автором. Метрики вычисляются из записей, а не подставляются из макета.
8. Отбор IT даёт 3 обращения и отсутствие измеренного первого ответа («—»). Отбор «Последние 7 дней / Бухгалтерия» даёт 0 обращений и корректное пустое состояние без NaN.
9. В эмуляции viewport 390 × 844 проверены навигация в две строки, герой с планетой, карточка полной ширины, укороченные колонки таблицы, метрики в две колонки. Найдено и исправлено переполнение контейнера диаграммы; график помещается в карточку. Декоративный Canvas ограничен границами своего фонового контейнера. После проверки временный viewport сброшен.

Демонстрационная запись и её комментарий сохранены в localStorage тестового браузера. Исходный seed проекта содержит 20 записей; новая установка начинает с него. PostgreSQL и исходники существующего Svelte/Go MVP в этой работе не изменялись.

## Реализовано без отдельного принудительного теста

- CSS-планета при отсутствии WebGL и Error Boundary для сцены.
- `prefers-reduced-motion`, остановка постоянного рендера при скрытой странице, невидимой сцене и открытом диалоге.
- Клавиатурные стрелки для табов и группы категорий, стандартный focus trap нативного dialog.

## Границы проверки

Проверка в узком viewport не заменяет реальный телефон. FPS на слабом устройстве, Lighthouse, INP, длительная GPU/CPU-нагрузка и подключение React-интерфейса к Go API не измерялись. Автоматические unit-тесты, повторяющие реализацию анимаций, не добавлялись; основная проверка — строгая типизация, production-сборка и фактические UI-сценарии.
