## Конфигурация и разрешение противоречий примера

- Слои: HeatmapCells, HeatmapXAxis, HeatmapYAxis, HeatmapTooltip, HeatmapSeparator; provider и boundary сохранены.
- HeatmapLegend отсутствует в импортах и JSX. Значение align=end неприменимо к скрытому слою. Оно не является поводом показывать легенду, оставшуюся в справочном JSX.
- Gap 2; cornerRadius 2; все пять levelStyles — solid / none с `var(--chart-scale-01)` … `var(--chart-scale-05)`.
- Separator: quarter, showLabels, `text-black dark:text-white`, `var(--border)`, spacing 12, startOffset 14.
- Enter transition задан явно: tween / 1.1 / `[0.85, 0, 0.15, 1]`; duration 1100, stagger scale 1.
- В установленном HeatmapChartProps нет animationEasing. Передавать несуществующее свойство не стали: та же кривая реально применяется через enterTransition в resolveHeatmapWaveTiming.
- Единственная смысловая настройка Tooltip — formatLabel: количество обращений на русском вместо англоязычных contributions. Панель, её стили и остальные параметры сохранены штатными.

## Смысл данных

Календарная сетка не подменяет таблицу «подразделение × тип»: эти оси имеют разный смысл. Bklit показывает календарь созданий по неделям и дням недели; прежняя карта сохраняет распределение и приоритеты по подразделениям.

Общие фильтры выделяют те же записи, что используются в метриках. Каждая запись учитывается по createdAt ровно один раз. UpdatedAt, комментарии, голоса, подтверждения и статусы не добавляют событий. Даты группируются по гражданским суткам Asia/Qyzylorda и преобразуются в календарные Date для стандартного API Bklit.

Пустые дни равны нулю, случайные события не генерируются. Календарь охватывает 12 календарных месяцев до текущего дня — форму стандартной годовой сетки Studio. Счётчик календаря относится только к этому окну; более ранние выбранные записи указаны отдельно и не пропадают из общих метрик. В исходном MVP даты двадцати записей демонстрационные; новые локальные обращения используют фактическое время создания.

- npm run build: строгая проверка TypeScript и production-сборка успешны.
- npm test: 30 тестов проходят, включая 7 новых проверок адаптера календаря.

- Старые 23 проверки логики, QR, контраста, орбит и частиц продолжают проходить.
- Встроенный браузер для визуального сравнения со Studio не использовался: ранее доступ к локальному сайту для такой проверки был отклонён. Пиксельное совпадение, касания на телефоне и поведение Tooltip в браузере не заявляются проверенными.
- Сборка сохраняет существующее предупреждение о крупном модуле Three.js.
