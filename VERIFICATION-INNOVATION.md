# Проверка InnovationSuite

11 ноября 2026; Windows, Node 24, production preview на `http://127.0.0.1:5175/`.

## Автоматическая проверка

- `npm run build`: TypeScript strict и Vite production build проходят.
- `npm test`: 10 проверок, 10 успешно. Проверяются точная формула ROI и границы, маршрутизация и неоднозначность, поиск похожего, идемпотентная поддержка и запрет поддержки своего обращения, SLA/ответы/граница 18 ч, однократная эскалация, промежуточный речевой текст, повторное подтверждение изменённого замера, безопасная QR-ссылка и независимое декодирование SVG-пути через jsQR.
- Подключение нового замера снимает подтверждение, обновляет текст результата и сохраняет прогноз отдельно. Подтверждение доступно только автору по демонстрационной модели личности; серверной аутентификации здесь нет.
- QR растеризуется из того же SVG-пути, который отображает компонент. Независимый декодер возвращает точный исходный URL с кириллической категорией.
- UI JS: 118.10 КБ / 37.10 КБ gzip; отложенный QR: 25.78 КБ / 10.14 КБ gzip; CSS: 51.68 КБ / 12.44 КБ gzip. Three-чанк: 931.90 КБ / 255.46 КБ gzip; предупреждение Vite о размере оставлено видимым. Эти размеры не доказывают целевую производительность.

## Границы проверки

Микрофон не включался и разрешение не предоставлялось. Проверена функция сборки промежуточного текста; реальное качество диктовки, доступность браузерного речевого сервиса и обработка разрешения на конкретном устройстве требуют ручной проверки пользователем. QR не сканировался физическим телефоном: проверены независимое декодирование SVG и открытие содержащейся в нём ссылки. Локальная очередь не доставляет обращения руководителю. Серверная авторизация, синхронизация браузеров, реальная пиковая нагрузка, INP и слабые устройства в этой React-версии не проверялись. Два тестовых обращения и демонстрационный замер находятся только в localStorage проверочного браузера; исходный seed содержит 20 записей.
