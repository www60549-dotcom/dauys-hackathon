# Версии обращения и история — 12 ноября 2026

## Изменения

- Миграция 003: version обращения, структурированные события истории,
  индекс событий статусов и триггер увеличения версии для всех записывающих путей.
- Runtime и sqlc читают один комплект SQL из backend/db. Дубли SQL в cmd/server удалены.
- Команды edit/manage/confirm отделены от модели ответа, поддерживают частичный PATCH.
- CAS-проверка выполняется под блокировкой строки; конфликты не создают историю
  или уведомления, не меняют чужие значения. Пустое фактическое изменение не увеличивает версию.
- Подтверждение и повторное открытие используют версию, просмотренную автором.
- Рабочие переходы ограничены сервером; закрытие отзыва отделено от подтверждения результата.
- Комментарии и вложения перепроверяют актуальные права и имеют атомарный журнал.
- При SSE-обновлении введённый текст и исходная версия формы сохраняются.
  Конфликт показывает сравнение; актуальная версия загружается явным действием пользователя.
- Дата в input соответствует календарю Asia/Qyzylorda, включая границу суток.
- OpenAPI основного workflow: api/workflow.openapi.json.

проверено интеграционным Go-тестом с контрольными суммами полных строк.
