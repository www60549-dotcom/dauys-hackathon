## Найдено и исправлено

1. На 390px вкладки аналитики увеличивали страницу до 435px. Добавлен существующий
   адаптивный класс analytics-subtabs: теперь страница 390px, длинные вкладки
   прокручиваются внутри своей панели. Полный браузерный прогон проходит.
2. В свежем demo seed благодарность ошибочно могла получить confirmed_at из-за
   проверки параметра категории вместо типа. Исправлено; новая CI-проверка
   подтверждает praise/actual_effect=0/confirmed=false.
3. Исторические demo-даты теперь получают срок первого ответа created_at+18ч,
   а не время установки демо+18ч. Проверены все 20 исходных записей.
4. В backup helper учтены права на Linux bind mount: экспорт архива выполняет
   отдельный одноразовый контейнер, пользователь приложения остаётся прежним.
5. После остановки среды PostgreSQL восстановился за 14 секунд, а скрипт ждал
   только 10 секунд. Окно ожидания увеличено до 60 секунд; повторный запуск
   прошёл. LAN-запуск также раздаёт production-сборку через API на порту 8080
   и передаёт этот адрес в QR. После восстановления в рабочей БД — 30 обращений
   и 105 записей истории, health и SPA deep link отвечают успешно.
