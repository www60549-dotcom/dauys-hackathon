# Приёмка объединённого Dauys

До отметки «проверено» пункт считается незавершённым.

| Сценарий | Экран / слой | Проверка |
| --- | --- | --- |
| Реальный вход и перезагрузка | Вход, профиль | HttpOnly cookie, `/api/me`, сохранение сессии |
| Выход / истечение сессии | Всё приложение | Поток закрыт, кеш пользователя очищен, API 401 |
| Создание A-001 / A-003 / A-009 | Форма, карточка | Сохранённые поля, назначение, история, корректный ID |
| Уточнение → ответ → решение → подтверждение | Сотрудник / исполнитель | Два пользователя видят один серверный цикл |
| Мотивированный отказ A-017 | Карточка | Обязательная причина, отдельный исход |
| Благодарность A-018 | Карточка, итоги | Отзыв не выдаётся за внедрение идеи |
| Права ролей | API и рабочие экраны | Запрет чужого изменения, серверные проверки |
| Поиск и пагинация | Список | Полный набор из БД, серверные счётчики |
| Файл и повтор загрузки | Форма, карточка | Авторизованное скачивание, лимит, без дубля обращения |
| Голос и поддержка проблемы | Идеи / похожие | Раздельные операции, безопасный повтор |
| Пилот / возврат проблемы | Бизнес-модули | Измерение, история, конфликт версий |
| Аналитика | Сводка, heatmap, эффект | Сверка с SQL, границы периода Asia/Qyzylorda |
| SSE и повторное подключение | Все рабочие экраны | Одно соединение, сверка состояния, отсутствие утечек |
| QR с телефона | Вход → форма | Доступный адрес, контекст сохранён после входа |
| WebGL / уменьшенное движение | Главная, переходы | Стабильная орбита, fallback, отсутствие зависаний |
| Production | Compose / эксплуатация | Чистый запуск без demo seed, backup и restore |
