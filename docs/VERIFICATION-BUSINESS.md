# Бизнес-модули — 13 ноября 2026

Подключены к рабочей карточке React:

- Цена ожидания: редактируемая месячная оценка времени/стоимости, сохранение
  в PostgreSQL, неизвестная ставка без выдуманной денежной суммы.
- Пилот: создание плана, редактирование до старта, запуск, измерение результата,
  вывод и серверная оценка достижения цели. История завершённых пилотов видна.
- Похожие обращения: серверный тематический поиск при вводе и в карточке,
  реальные причины совпадения и статусы, исключение текущей записи.

Сохранение оценки и все команды пилота проверяют expected_appeal_version.
Команды существующего пилота дополнительно проверяют его version.
GET features читает согласованный PostgreSQL snapshot. Черновики не получают
новую версию автоматически и сохраняют введённые значения при SSE/конфликте.
Одновременно редактируется одна форма; остальные действия блокируются до
сохранения или явной загрузки текущих данных.

Благодарности не превращаются в «потери» или внедрённые идеи. Успешный пилот
не приписывает финансовый эффект: для этого остаются решение и подтверждение автора.

## Локальный сервер

Новая версия Go собрана в backend/bin/dauys-next.exe и проверена на отдельном
API с восстановленной тестовой БД. Автоматическая проверка отклонила команду
остановки и перезапуска основного API: `blocked by policy`. Более подробная
причина не предоставлена. Команда не выполнилась; основной API на 8080 остался
на предыдущей версии, Vite на 5175 продолжает работать.

Перед попыткой создана копия `data/backups/before-business-deploy-20261113_004206.dump`.
После отказа проверены HTTP 200 сайта и health API. В основной БД по-прежнему
30 обращений, 105 событий истории, миграция 3; контрольная сумма истории
`77c853656abad54d4d21fff456d92344` совпала.

Для подключения новых модулей к основному сайту нужно выполнить в терминале
из корня проекта:

```powershell
./stop-local.ps1
./start-local.ps1 -DemoMode $false
```

Скрипт соберёт текущие исходники API; повторный demo seed отключён.
До обновления сервера формы оценки/пилота сообщают об обновлении сервиса,
не подставляя моковые данные и не отправляя неверсионные изменения.
Временный API на 8081 остановлен после завершения проверок.

Браузерный E2E, визуальная приёмка на телефоне, Docker/Linux и нагрузочное
профилирование не выполнялись на этом этапе. Тесты HTTP не заменяют эти проверки.
Серверная эскалация, идемпотентность создания и финальный production-деплой остаются в плане.
