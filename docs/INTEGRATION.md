## Контрольная точка

- Перед переносом создан ZIP исходного React в соседней папке `Dauys-backups/`.
- Backend перенесён без исполняемых файлов и без изменения бизнес-логики.
- Старые API-проверки находятся в `tests/api/`.
- Исторические отчёты находятся в `docs/legacy/`; они не заменяют новый прогон.
- PostgreSQL-кластер не переносится и не удаляется. Локально можно использовать
  существующий кластер через `DATABASE_URL`; uploads скопированы отдельно.
- Локальные React-обращения из localStorage не импортируются в PostgreSQL.

## Правила контракта

- Wire DTO сохраняют существующие snake_case; UI использует адаптеры.
- Пользователь и права берутся из `/api/me`, а не из имени или localStorage.
- Даты API — RFC3339, время UI — epoch milliseconds; календарь Asia/Qyzylorda.
- `resolved` означает подготовленное решение, `closed` — подтверждение автора.
- Голос за идею и сообщение о такой же проблеме — разные операции.
- Прогноз ROI, цена ожидания и подтверждённый эффект — разные показатели.
- Серверные ошибки никогда не подменяются демонстрационными данными.
- Один origin браузера: `http://127.0.0.1:5175`, API через `/api` proxy.

## Проверки

Перед изменениями фиксируются `npm run check`, `npm test`, `go test ./...`,
`go vet ./...`. После интеграции API-сценарии запускаются только в отдельной
тестовой БД, поскольку они создают обращения и комментарии.
